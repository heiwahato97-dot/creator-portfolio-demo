# Creator Portfolio Demo

HTML / CSS / JavaScriptで制作した、レスポンシブ対応のクリエイター向けポートフォリオWebサイトです。

## Demo

GitHub Pagesで公開しています。

https://heiwahato97-dot.github.io/creator-portfolio-demo/

## 概要

イラスト、3Dモデリング、ゲーム制作などの作品や学習記録を掲載するポートフォリオサイトを想定して制作しました。

PCとスマートフォンの両方で閲覧できるレスポンシブデザインに対応しています。

## 主な機能

- ヘッダーナビゲーション
- Aboutセクション
- Worksカード表示
- Learning Log
- JavaScriptによる表示切り替え
- レスポンシブレイアウト
- ページ内スムーズスクロール
- GitHub PagesによるWeb公開

## 使用技術

- HTML
- CSS
- JavaScript
- Git
- GitHub Pages

## ファイル構成

```text
creator-portfolio-demo/
├── index.html
├── style.css
├── script.js
└── README.md
```

## レスポンシブ対応

画面幅が狭い場合、Worksの3列レイアウトを1列に変更し、ナビゲーションやタイトルもスマートフォン向けに調整します。

## JavaScript

Learning Logのボタンをクリックすると、最新の学習記録の表示・非表示を切り替えます。
